# Excel 模板列位（自己建一张空表即可）

| 列 | 含义 | 说明 |
|---|---|---|
| A | 序号 | |
| B | ip 地区 | 城市锚点（可选） |
| C | 标题 | ≤15 字 |
| D | 正文 | 13–14 段 |
| E | 话题 | 5 个真实话题 |
| F–N | 图片 1–9 | 成图内嵌于此（9 组版）；8 组版到 M |
| O | 参考图 | 抓来的真实封面，按顺序内嵌 O2/O3/O4…（2026-09-21 起固定用 O 列；**浮动内嵌**，不是 URL） |
| P | 反推提示词 | 只含环境与拍摄 |
| Q | 人脸图 | 你自己的模特脸（WPS `DISPIMG` 内嵌） |
| R–S | 上身效果图（R 正面 / S 背面） | **服装主源**（2026-09-21 起）：生成时的正/反面服装以此为准 |
| T–W | 平铺图（T/U 上衣正反 · V/W 下装正反） | **细节补充**：仅当 R/S 上身图看不清面料/领型/腰头/车线时参考 |
| X | 首图 | 生成的首图 |
| Y–AG | 动作提示词 1–9 | 每格一组 |
| AH | 平台热门话题 | 可选 |

## 两种内嵌方式

- **浮动图（推荐）**：写进单元格锚点，脚本可保留 WPS 的 `DISPIMG` 参考图 —— 本项目采用这种方式
- **WPS DISPIMG**：Excel 原生不支持，Python 侧只读不改

## 快速造空表

```bash
python3 - <<'PY'
from openpyxl import Workbook
wb = Workbook(); ws = wb.active
heads = ["序号","ip 地区","标题","正文","话题"] + [f"图片{i}" for i in range(1,10)] + \
        ["参考图","反推提示词","人脸图","上身效果图1","上身效果图2"] + [f"平铺图{i}" for i in range(1,5)] + \
        ["首图"] + [f"动作提示词{i}" for i in range(1,10)] + ["平台穿搭热门话题"]
ws.append(heads)
for r in range(2, 7): ws.cell(r, 1, r-1)
wb.save("图片笔记导入模板.xlsx")
PY
```
