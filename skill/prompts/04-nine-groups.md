# 阶段 3 · Y–AG 九组动作提示词（配额 + 格式）

## 输出格式（每格一行，七槽位）

```
【组N】机位｜景别｜动作｜视线｜接触关系｜光影变化｜一句话完整生图提示词（含环境、相机点位、景别、主体聚焦、背景柔和低肌理虚化、抓拍质感与统一的人物服装锁词）
```

- **动作必须取自【RV 内容提示词库】**（`references/10-action-library.md`，11 族 120+ 条），带上编号（如 `S08 双手插兜微收下巴`），**不要自由发挥**
- 同一空间内**只改机位/景别/动作/视线/接触关系**；空间结构、家具、门窗、地面、陈设、色调、服装配饰全部不变

## 两套配额口径（用 `--quota std|relaxed` 选）

| 维度 | **std**（默认，严格版） | **relaxed**（客户 2026-09-18 口径） |
|---|---|---|
| 机位·正面 | ≥2 | **正面全身 ≥2** |
| 机位·3-4侧 | ≥2 | ≥1 |
| 机位·全侧 | ≥1 | ≥1 |
| 机位·背面 | ≥1 | **背面全身 ≥1** |
| 景别·全身 | ≥4 | ≥4 |
| 景别·七分 | ≥2 | ≥1 |
| 景别·半身 | ≥2 | ≥1 |
| 景别·特写 | ≥1 | ≥1 |
| 看镜头 | ≤2 | ≤2 |
| 其他 | 机位/景别/动作各 ≥3 种不同值；不允许两组以上完全同款；留 1 组给局部特写（配饰/面料验收镜头） | 同左 |
