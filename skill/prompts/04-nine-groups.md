# 阶段 2 · Y–AG 九组动作提示词（配额 + 格式）

## 输出格式（每格一行，七槽位）

```
【组N】机位｜景别｜动作｜视线｜接触关系｜光影变化｜一句话完整生图提示词（含环境、相机点位、景别、主体聚焦、背景柔和低肌理虚化、抓拍质感与统一的人物服装锁词）
```

- **动作**必须取 `references/10-action-library.md` 的条目（带编号，如 `S08 双手插兜微收下巴`），不要自由发挥
- 同一空间内**只改机位/景别/动作/视线/接触关系**；空间结构、家具、门窗、地面、陈设、色调、服装配饰全部不变

## 配额（{{组数}} 组版必须逐项满足）

| 维度 | 要求 |
|---|---|
| 机位 | 正面 ≥2 · 3-4侧 ≥2 · 全侧 ≥1 · 背面 ≥1 |
| 景别 | 全身 ≥4 · 七分 ≥2 · 半身 ≥2 · 局部特写 ≥1 |
| 视线 | 「看镜头 / 侧目看镜头」合计 **≤2** |
| 覆盖性 | 机位/景别/动作各 ≥3 种不同值；**不允许两组以上完全同款** |
| 配饰验收 | 留 1 组给**局部特写**（手部/腕部/耳部配饰），它是配饰零增零减的硬验收镜头 |
| 活人气息 | 允许并推荐生活化交互：捧咖啡杯、拨弄发丝、侧身看手机、轻扶包带、整理袖口 |

## 自查

```bash
python3 scripts/check_action_distribution.py --file <提示词文件> --groups {{组数}} --cols {{动作列}}
```
