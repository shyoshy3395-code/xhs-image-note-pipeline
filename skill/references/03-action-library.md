# 【动作提示词库】（街拍 / 空间 / 视频分镜通用）

> **名称：【动作提示词库】**（编号 `A01` · 文件 `references/03-action-library.md`）
> 本库**唯一正式名称**——其他叫法（动作库 / 动作词库 / 动作素材库 / 动作条目库）一律以此为准；
> 对外引用、触发词、回复里提到本库时都用**【动作提示词库】**。

> **定位**：`08` 定「格式与强制分布」· `07` 定「锁块与约束」· 本篇提供**可选动作素材**——写 Y–AG 时从这里取，
> 不要每行重新想。目标：同一个模特、同一套衣服、同一个空间，做出**互不重复、又都不像摆拍**的动作。
> 口径来源：0913 / 0914 两轮实测（行2 街拍 · 行3 清水混凝土空间）+ 品牌调性「自在·真实·蓬勃 / 不费力的在场感」。

> → 跑 `bash ~/.hermes/sync_skills.sh`。5 个角色 profile 的副本是**只读**的，改了也会被下次同步覆盖。
> 其他角色（COCO / Coni / Neo / Shane）只读引用，需改请在 Aim 会话里提出。

## 一、怎么用（三步，别跳）

```
① 定组数      读表头 → 8 组 或 9 组        → 配额见 §二 / 08 §三 / 07 §11.2
② 抽组        按 §四 抽组顺序，从 §三 条目库里挑（先定额度，再选动作）
③ 闸门        落 Y–AG 前跑 scripts/check_action_distribution.py 自检 → 不过不落表
```

**抽组顺序（关键：先定额度再选动作，反了必超配）**

```
1. 按机位额度把组号排满 → 2. 按景别额度把组号排满 → 3. 从动作族里挑动作填空
4. 视线：看镜头 ≤2 组 → 5. 生活化交互放 3–5 组 → 6. 局部特写那组留给配饰 → 7. 跑闸门
```

## 二、六槽位值域（只在这些值里选，禁止自由发挥）

| 槽位 | 可选值 | 计数规则 |
|---|---|---|
| **机位** | **正面** / **3-4侧** / **全侧** / **背面**（四大类，**必须写在最前**）<br>变体写在括号里：`正面(仰拍)` `3-4侧(俯拍)` `背面(过肩)` `全侧(跟拍)` `正面(微侧15°)` | 闸门只认四大类；括号里的变体**不另计数** |
| **景别** | 全身 / 七分 / 半身 / 局部特写 / 全景空镜带人 | 8 组版不用后两个（8 组的额度刚好占满） |
| **视线** | 看镜头 / 侧目看镜头 / 看向画外 / 低头 / 抬头 / 闭眼 / 不可见（背影·特写） | **「看镜头」「侧目看镜头」合计 ≤2** |
| **接触关系** | 无接触 / 自身接触（手触身体或衣物） / 道具接触 / 环境接触（倚靠·坐·台阶扶手） / 他人在画面但无互动 | 写清接触物，锁块靠它守配饰 |
| **光影变化** | 受光面偏正 / 侧光加强 / 轮廓光 / 进入遮挡阴影 / 地面投影可见 | ⚠️ **只调受光面，光向与时段锁定不动**（15:30–17:00 侧逆光） |
| 动作 | 从 §三 取，写「正在做某事的一瞬间」 | 9 组不得重复；族分布见 §四 |

**时段词禁用**（闸门会拦）：清晨 / 早晨 / 正午 / 中午 / 傍晚 / 黄昏 / 夜晚 —— 混光 = 观感上等于换了地方。

## 五、品牌调性过滤（先过这一关，再谈配额）

> 判准一句话：**像是被随手拍到的，不是被要求摆的**（不费力的在场感）。做不出的动作就删，别硬凑。

**允许且推荐**：走 / 停 / 看 / 整理（衣、袖、发、配饰） / 倚靠 / 坐 / 蹲 / 俯身 / 低头 / 自然笑 / 半动作抓拍

**禁止（不进库，出现即删）**

| 类别 | 禁项 |
|---|---|
| 网红摆拍 | 比耶、双手比心、嘟嘴、贴墙翘臀回头杀、叉腰挺胸模特站、蹲地压腿、抬腿压脚背 |
| 夸张动态 | 跳起、奔跑、旋转跳跃、**躺地（仅禁户外躺地摆拍）**、劈叉、飞纱、泼水 |
| 情绪过头 | 咬唇、媚眼、仰头苦大仇深、皱眉用力、假惊讶 |
| 道具红线 | 酒杯、香烟、奢侈品包袋 Logo、他牌包装袋、夸张花艺、网红装置、大型道具 |
| 画面红线 | 任何文字/字母/数字/Logo/招牌/路牌/菜单/包装文字（含手机屏幕与书页） |

**边界提醒**：动作可以「不完整」——手抬到一半、脚刚离地、刚停下，都比标准姿势更像真的。
`M` 族存在的意义就是这个：**抓中间态，不抓完成态**。

### 范例 C · 视频分镜映射（Seedance 用）

同一个动作命中视频时，把 §三 的片段**切成三拍**（不要另起一套动作清单）：

| 拍 | 时长 | 写法 |
|---|---|---|
| 起势 | 0–1s | 动作还没开始、身体正在蓄力（如「手正抬向杯口」） |
| 动作中段 | 1–3s | 用条目原文（如「低头喝一口，杯口贴唇，眼睛看向别处」） |
| 收势余势 | 3–5s | 动作结束后的余势（如「放下杯子，视线回到街上」） |

- 视频用「正在…的一瞬间 / 一边…一边…」叙述，避免「首先 / 然后 / 接着」这类分镜词
- 镜头仍要写死：`机位 + 景别 + 是否移动（跟拍/固定/微推）`，等效于图片的六槽位
- 光向与时段同样锁定，不写「日出/正午/黄昏」等时段词
