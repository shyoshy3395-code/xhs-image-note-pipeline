# 架构与闸门

## 四阶段

| 阶段 | 输入 | 命令/动作 | 产物 | 人工确认 |
|---|---|---|---|---|
| 0 封面 | 话题检索 | opencli 搜索 + 节流下载 + 3:4 裁切 | 参考图（内嵌单元格） | ✅ 必须人眼过（官方海报/教学图卡/九宫格/文字贴纸/违禁道具都要淘汰） |
| 1 反推 | 封面图 | 读图写 5 段英文 | P 列提示词 | ✅ 它是后续一切的基准 |
| 2 出图 | P + 人脸/上身/平铺 | `pipeline_loader` → `run_image_note` | 首图 + 9 组 | ✅ 拼接触表逐张查一致性 |
| 3 文案+回填 | 知识库 + 成图 | 写 C/D/E → 降噪 → 内嵌 → 闸门 | 成品 xlsx + 上传图 | ✅ 过闸门 |

## 两道自动闸门

1. **配额闸门**（`pipeline_loader.py` 内置 `check_quota`）
   - 机位：正面≥2 · 3-4侧≥2 · 全侧≥1 · 背面≥1
   - 景别：全身≥4 · 七分≥2 · 半身≥2 · 局部特写≥1
   - 视线：看镜头 ≤2；动作条目不得重复
2. **交付闸门**
   - 参考图仍在 · 锚点数正确 · WPS `DISPIMG` 未被破坏
   - **内嵌图显示尺寸 ≥60px 且比例 3:4**（专治 15×20px）
   - 文案合规（禁用词）

## 为什么提示词要外置

锁块、配额、文案规格会随品牌与平台规则变化。把提示词放进 `prompts/*.md`、由脚本实时读取，
就能**改文案不用改代码**，也方便非工程同学参与迭代（改完 `--check` 自检即可）。
