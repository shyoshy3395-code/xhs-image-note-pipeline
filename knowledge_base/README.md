# knowledge_base · 你的品牌素材

流水线在**写文案**时会从这里取料（`prompts/05-copywriting.md` 规定了取料顺序）。
不填也能出图，但文案会缺少品牌依据。

| 文件 | 放什么 | 被谁用 |
|---|---|---|
| `01-brand.md` | 品牌定位 / Slogan / 语气 / 对外口径（白名单-黑名单） | 阶段 3 写文案前的第一道 |
| `02-product.md` | 单品卖点（版型/设计/面料/穿着利益/风格场景） | 文案取词，避免自创形容词 |
| `03-compliance.md` | 禁用词表 + 安全替代（广告法/行业敏感） | 发布前自检闸门 |
| `05-channel.md` | 各渠道语气与规格（天猫/社媒/私域/活动） | 换渠道不换调性 |

> 建议：**一个单品一个条目**，每条 5–6 个字段。素材越具体，文案越不像 AI 写的。
